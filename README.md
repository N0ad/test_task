CUDA-ядра предназначенны для параллельных вычеслений как и Tensor-ядра, но последние оптимизированны под матричные вычисления.

CUDA-ядра применяются при обучении нематричных ML-алгоритмов(например бустинг, k-means), вспомогательных вычислениях (например функция потерь). Tensor-ядра применяются при работе с большим количеством матричных вычислений(глубокие нейронные сети, Transformer).

Tensor-ядра дают преимущество в архитектурах с большим количеством слоев, требующих матричных вычислений, например в Transformer со множеством слоев Attention.

Tensor-ядра есть в большинстве GPU от NVIDIA с архитектурой не старше 2017 года. Присутствуют как в потребительских моделях(RTX 20.., 30.., 40.., 50..), так и в серверных(A100, V100).
